# BOSS直聘 JD 抓取助手（MV3 Chrome 扩展）

在 BOSS直聘 岗位详情页一键抓取 JD 全文到本地，自动展开折叠、自动去重，供求职分析使用。

## 功能

- **悬浮按钮**：访问 BOSS直聘 岗位详情页时，右下角出现「抓取JD」按钮
- **自动展开**：自动点击 JD 描述里的「查看更多/展开」按钮，抓取完整描述；若文本过短会标记「可能不完整」
- **自动去重**：按「公司+岗位名+薪资」生成指纹，重复岗位自动跳过或更新
- **本地存储**：数据仅存在浏览器本地（chrome.storage.local），不经过任何服务器
- **一键导出**：弹窗里可「复制全部」（JSON，供粘贴到 WorkBuddy 分析）或「导出JSON文件」

## 安装步骤（Chrome / Edge）

1. 打开浏览器扩展管理页：
   - Chrome：地址栏输入 `chrome://extensions`
   - Edge：地址栏输入 `edge://extensions`
2. 打开右上角 **开发者模式** 开关
3. 点击 **加载已解压的扩展程序**
4. 选择本目录：`boss-jd-extension/`
5. 完成！访问 BOSS直聘 任意岗位详情页，右下角出现绿色「抓取JD」按钮

## 使用流程

1. 登录 BOSS直聘 → 打开岗位详情页（URL 形如 `https://www.zhipin.com/job_detail/xxxx.html`）
2. 点击右下角「抓取JD」→ 出现「已抓取 xxx」提示
3. 抓完多个岗位后，点扩展图标打开弹窗
4. 点「复制全部」→ 把 JSON 粘贴到 WorkBuddy 对话中分析
   （或点「导出JSON」保存文件，再把文件内容贴进来）

## 文件结构

```
boss-jd-extension/
├── manifest.json   # MV3 配置：权限、content script 匹配规则
├── content.js      # 悬浮按钮 + DOM 抓取 + 展开 + 去重 + 存储
├── popup.html      # 弹窗界面
├── popup.js        # 列表渲染 / 复制 / 导出 / 清空
└── icons/          # 16/48/128 图标
```

## 注意

- **只抓取页面可见文本**（DOM），不调用站内 API，合规安全
- 若 BOSS直聘 改版导致选择器失效，抓取会提示「解析失败」，更新 `content.js` 中 `pick()` 的选择器即可
- 数据存浏览器本地，清除浏览器数据会一并清除抓取记录，建议及时导出备份
