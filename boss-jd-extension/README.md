# 招聘 JD 抓取助手（MV3 Chrome 扩展）

在 **BOSS直聘 / 智联招聘** 岗位页一键抓取 JD 全文到本地，自动展开折叠、自动去重，供求职分析使用。

## 支持的平台与页面

| 平台 | 详情页 | 列表页 | 说明 |
|---|---|---|---|
| BOSS直聘 | ✅ 抓取完整 JD | ✅ 抓取选中卡片的预览 JD | 列表页有预览面板，直接出全文 |
| 智联招聘 | ✅ 抓取完整 JD | ✅ 批量抓取卡片元数据 | 列表页**无完整 JD**，只抓岗位名/薪资/公司/地址等元数据，全文需进详情页补齐 |

## 功能

- **悬浮按钮 + 快捷键**：访问支持页面时右下角出现抓取按钮，也可按 `⌘⇧J`（Mac）/ `Ctrl⇧J`（Win）触发
- **自动展开**：BOSS 详情页自动点击「查看更多/展开」抓取完整描述
- **自动去重**：按平台 + jobId（缺失时按公司+岗位名+薪资）生成指纹，重复岗位自动跳过或更新
- **本地存储**：数据仅存浏览器本地（chrome.storage.local），不经过任何服务器
- **一键导出**：弹窗里「复制全部」（JSON，供粘贴到 WorkBuddy 分析）或「导出 JSON 文件」

## 安装步骤（Chrome / Edge）

1. 打开浏览器扩展管理页：
   - Chrome：`chrome://extensions`
   - Edge：`edge://extensions`
2. 打开右上角 **开发者模式**
3. 点击 **加载已解压的扩展程序**
4. 选择本目录 `boss-jd-extension/`
5. 完成。访问支持页面，右下角出现抓取按钮

## 使用流程

### BOSS直聘

1. 登录 → 打开岗位详情页（`zhipin.com/job_detail/xxx.html`）或列表页
2. 点「抓取JD」/「抓取预览」→ 提示「已抓取 xxx」
3. 抓完后点扩展图标 → 「复制全部」粘贴到 WorkBuddy 分析

### 智联招聘

1. 打开搜索列表页（`sou.zhaopin.com`）→ 点「批量抓取列表」，一次性采集当前页所有岗位卡片
2. 对感兴趣的岗位，点进详情页（`jobs.zhaopin.com/CCxxx.htm`）→ 点「抓取智联JD」补全全文
   - 详情页会用相同 jobId 覆盖掉列表页那条元数据，不会产生重复
3. 抓完后「复制全部」导出 JSON

## 文件结构

```
boss-jd-extension/
├── manifest.json   # MV3 配置：双平台 host 权限、content script 匹配
├── content.js      # 悬浮按钮 + 双平台抓取 + 展开 + 去重 + 存储
├── popup.html      # 弹窗界面
├── popup.js        # 列表渲染 / 复制 / 导出 / 清空
└── icons/          # 16/48/128 图标
```

## 注意

- **只抓取页面可见文本（DOM）**，不调用站内 API，合规安全
- 智联列表页抓的是元数据，`fullText` 为空、`complete=false`，在 WorkBuddy 的 jd-matcher 里会被标记「可能不完整」，需补详情页全文才能做完整分析
- 若平台改版导致选择器失效，抓取会提示「解析失败」，更新 `content.js` 中 `pick()` 的选择器即可
- 数据存浏览器本地，清除浏览器数据会一并清除，建议及时导出备份
